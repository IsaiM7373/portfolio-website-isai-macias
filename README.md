
    For this project, I wanted a clean layout that didn't feel clunky or rely on a random hamburger menu. I went with a split-pane style inspired by some developer portfolios I liked.

### 1. Fixed Sidebar (Left Pane)
* **Desktop:** Stays locked on the left side of the screen so my profile picture, title ("Future Network Admin"), bio, and navigation links are always right there.
* **Mobile:** Automatically collapses to the top of the screen on smaller devices so it scales properly.
* **Navigation:** Switches smoothly between tabs without forcing the page to reload.

### 2. Main Content Area (Right Pane)
This is where the different pages load:
* **Home:** A quick intro talking about my goals to become a network admin, plus a card highlighting what I'm currently studying (like the CompTIA Network+).
* **About:** Breaks down my background, education, and the networking/tech stuff I'm interested in.
* **Portfolio:** Pulls my public repos straight from the GitHub API automatically. I added a live search bar and a language dropdown so people can filter through my projects easily.
